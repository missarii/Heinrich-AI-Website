Philosophy

An agent that stays honest

Heinrich AI is designed so you always understand what happened and why. Approvals are explicit. Actions are logged. Checkpoints are recoverable. The goal is not to replace the engineer — it is to amplify disciplined engineering.

FAQ

Frequently asked questions about Heinrich AI

What is Heinrich AI?

Heinrich AI is a free autonomous coding agent extension for Visual Studio Code. It plans tasks, reads your project, edits files, runs terminal commands, and can control a browser — always with your explicit approval.

Is Heinrich AI free to use?

Yes. The extension is free on the Visual Studio Marketplace. You supply API keys for the providers you want.

How do I install Heinrich AI?

Go to the VS Code Marketplace page, or search for Heinrich AI in the VS Code Extensions view.

What makes Heinrich different?

Human-in-the-loop control, git checkpoints, full action history, multi-provider support, and a native MCP ecosystem (Overthink + Mila). Built for serious engineering.
